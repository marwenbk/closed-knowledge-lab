# Family members and dependents

Canonical policy: **TM-DEP-005**.

## Dependent limits

- The Essential plan allows **0 dependents**.
- The Family plan allows **up to 3 dependents**.
- The Premium plan allows **up to 5 dependents**.

## Individual registration

- Each dependent requires a separate profile.
- A dependent's profile must be registered before the first consultation.
- Dependents may be minors.
- A dependent may be linked to only one active consumer account.

## Billing relationship

- Adding a dependent does not restart the account's billing cycle.
- The limit comes from the active consumer plan.
- For employer-sponsored benefits, first identify which consumer plan maps to the employer tier in the employer-plans document.

This document is the canonical source for dependent limits. It does not repeat employer-tier mappings.

## Applying the limits

The limit counts registered dependent profiles. The Essential plan has no dependent places. The Family limit is 3, and the Premium limit is 5. The account holder is not counted as a dependent because that is a separate role.

Adding a profile within the limit does not automatically confirm a consultation. The dependent must be registered before receiving care, and the correct profile must be confirmed during the consultation flow. Minor dependents are allowed but still require their own profiles.

## Employer benefit

For an employer account, the employer tier does not directly state a dependent limit. The sponsored-plans document first identifies the equivalent consumer plan. This document then supplies that plan's limit. This two-document path is required for questions about the Gold tier.

## Common situations

A Family account with fewer than 3 registered dependents can add profiles until it reaches the limit. An account already at the limit must not be promised another place.

A dependent already linked to an active consumer account cannot be treated as available for a second active account. Adding a new dependent also does not create a new billing date or restart the existing cycle. The knowledge base defines no additional charge calculation.

## Required evidence

An answer must identify the plan before stating a quantity. If the user says only “my plan” or “can I add someone,” there is not enough context to select the correct limit. A short clarification should ask which plan or employer tier applies.
