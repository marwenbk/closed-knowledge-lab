# Membros da família e dependentes

Política canônica: **TC-DEP-005**.

## Limites de dependentes

- O plano Essencial permite **0 dependentes**.
- O plano Família permite o cadastro de **até 3 dependentes**.
- O plano Premium permite o cadastro de **até 5 dependentes**.

## Cadastro individual

- Cada dependente exige um perfil separado.
- O perfil do dependente deve ser registrado antes da primeira consulta.
- Dependentes podem ser menores de idade.
- Um dependente pode estar vinculado a somente uma conta de consumidor ativa.

## Relação com a cobrança

- Adicionar um dependente não reinicia o ciclo de cobrança da conta.
- O limite vem do plano de consumidor ativo.
- Para benefícios patrocinados por empresa, primeiro é necessário identificar qual plano de consumidor corresponde ao nível empresarial; essa correspondência está no documento de planos empresariais.

Este documento é a fonte canônica dos limites de dependentes. A correspondência entre níveis empresariais e planos não é repetida aqui.

## Aplicação dos limites

O limite conta perfis de dependentes cadastrados na conta. No Essencial, não existe vaga para dependente. No Família, o teto é 3; no Premium, o teto é 5. O titular não deve ser contado como dependente, pois exerce um papel separado.

Adicionar um perfil até o limite não confirma automaticamente uma consulta. O dependente precisa estar registrado antes de seu primeiro atendimento e o perfil correto deve ser confirmado durante o fluxo. Dependentes menores são aceitos, mas continuam sujeitos ao cadastro individual.

## Benefício empresarial

Quando a conta vem de uma empresa, o nível empresarial não informa diretamente o limite. Primeiro, o documento de planos patrocinados determina o plano de consumidor equivalente. Em seguida, este documento fornece o limite daquele plano. Esse caminho é necessário, por exemplo, para responder a perguntas sobre o nível Gold sem copiar a quantidade de dependentes para o documento empresarial.

## Situações comuns

Uma conta Família com menos de 3 dependentes cadastrados ainda pode adicionar perfis até alcançar o teto. Uma conta que já alcançou o teto não deve receber a promessa de mais uma vaga.

Um dependente já ligado a uma conta de consumidor ativa não pode ser tratado como disponível para uma segunda conta ativa. A regra evita interpretar o mesmo perfil como dois dependentes independentes.

O cadastro de um novo dependente não cria uma nova data de cobrança e não reinicia o ciclo atual. Isso não define um valor proporcional ou uma nova tarifa; apenas preserva o ciclo existente.

## Evidência necessária

Uma resposta deve identificar o plano antes de informar a quantidade. Se o usuário disser apenas “meu plano” ou “posso adicionar alguém”, falta contexto para escolher entre os três limites. Nessa situação, uma pergunta curta sobre o plano ou nível empresarial é mais segura do que assumir uma opção.
